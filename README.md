# Tandem 0.1.1

**Готовая сборка Windows:** [Tandem-0.1.1-Windows-x64.zip](https://github.com/lemeschenkoartem/Tandem/releases/download/v0.1.1/Tandem-0.1.1-Windows-x64.zip)

[Страница релиза и инструкция](https://github.com/lemeschenkoartem/Tandem/releases/tag/v0.1.1). Распакуйте архив целиком и запустите `Tandem.exe`. Для подключения двух квартир нужен общий VPN (Tailscale или Radmin VPN); публичный сервер автоматически не разворачивается.

Настольный прототип для двух Windows 10/11 x64 ПК: трансляция всего монитора,
системный звук, клавиатура и мышь, аккаунты с постоянным ID из 8 цифр и поиск друга.
Подключение, ввод и смена ролей требуют согласия второго участника.
Регистрация выполняется сразу, без почты.

Инструкция для готовой сборки: [START-HERE.txt](START-HERE.txt).

## Запуск исходников

Нужен Node.js 24 LTS x64 и npm. На Windows:

```powershell
npm ci
npm start
```

Оба клиента должны использовать **один сервер**. Встроенный сервер запускает
один клиент, либо сервер запускается отдельно:

```powershell
npm ci --omit=dev
npm run server
```

Порт по умолчанию 8787; `PORT`, `HOST`, `DATA_DIRECTORY` задаются переменными
окружения. Серверу нужен Node.js 24+. Аккаунты хранятся в SQLite, пароли — scrypt
с отдельной случайной солью. Случайные ID уникальны в пределах базы и сохраняются
после перезапуска. У разных серверов разные базы аккаунтов.

Для первого соединения через интернет используйте Tailscale или Radmin VPN.
Адреса Radmin VPN 26.x.x.x поддерживаются. Приватный сервер работает на одном ПК.
Нажмите «Скопировать приглашение» и передайте всю строку другу: она выбирает
общий сервер и проверяет идентификатор его базы до регистрации/входа.
ID действует в пределах этой базы, а не во всех установках Tandem.
Ошибка поиска, отказ и завершение сессии сохраняют аккаунт и WebSocket;
выйти можно отдельной кнопкой. Обновлять до 0.1.1 нужно оба клиента. Встроенный сервер
слушает интерфейсы ПК на TCP 8787; не публикуйте WS без TLS в интернет.
Для отдельного сервера есть [deploy/Caddyfile](deploy/Caddyfile), который завершает
TLS и проксирует WebSocket. Видео и ввод передаются по DTLS/SRTP WebRTC.

## Сборка Windows

```powershell
npm ci
npm run check
npm test
npm run package:win
```

Результат: `release/Tandem-win32-x64/Tandem.exe` и соседние файлы. Для распространения
архивируйте всю папку. Сборка не подписана сертификатом разработчика.
При сборке на Linux дополнительно положите официальный пакет
`@koromix/koffi-win32-x64@3.3.7` в `node_modules/@koromix/koffi-win32-x64`;
в Windows npm устанавливает его автоматически. Скрипт проверяет его наличие.

## Архитектура

- `app/main.cjs`: захват экрана Electron, IPC, встроенный сервер, горячая клавиша,
  разрешение ввода, перевод координат выбранного монитора с учётом DPI, watchdog.
- `app/windows-input.cjs`: прямой `user32.SendInput` через Koffi, физические scan-коды,
  абсолютная и относительная мышь, освобождение удерживаемых кнопок и клавиш.
- `app/renderer.js`: WebRTC, H.264/VP9/AV1 preference с fallback, профили 1080p–4K,
  60–240 FPS, статистика, два канала данных (надёжный для нажатий и ненадёжный
  для устаревающих координат), низкая целевая буферизация видео, смена ролей.
- `server/relay.cjs`: регистрация/вход, поиск ID, запрос и принятие подключения,
  SDP/ICE между двумя принятыми участниками, лимиты запросов и соединений.
- `app/network.js`: проверка VPN/WSS адресов и приглашения с адресом и ID базы.
- `server/accounts.cjs`: SQLite, стабильный идентификатор базы и scrypt. Ни пароль, ни полноценный удалённый
  ввод не передаются в произвольные команды ОС.

Управление выключается при разрыве, отзыве, смене монитора и завершении.
При потере heartbeat нативный watchdog отзывает управление за 3–3.25 секунды.
При потере фокуса у зрителя отпускаются удерживаемые клавиши.
Ctrl+Alt+F12 зарегистрирована локально; если сочетание занято, передача ввода блокируется.

## Обновление 0.1 → 0.1.1

Таблица аккаунтов не меняется; в существующую SQLite добавляется таблица метаданных
с постоянным идентификатором сети. ID и хеши паролей сохраняются на том же сервере.
Новый клиент ждёт handshake протокола 2, поэтому сервер/встроенный клиент владельца
тоже нужно обновить. Приглашение не содержит пароль, авторизационный токен или TURN
credentials. Явная смена сервера требует нового входа, поскольку там другая база.

## Проверка

`npm test` проверяет границы входных данных, сохранность ID и паролей, поиск,
подтверждение/отклонение подключения, недопуск третьего участника, обмен SDP
после смены ролей и завершение при уходе владельца.

`npm run test:browser` требует Playwright и Chromium (`CHROMIUM_PATH`).
Сценарий поднимает два изолированных браузерных клиента и два независимых сервера,
воспроизводит ошибку поиска в другой базе и повторные попытки без потери входа,
проверяет импорт приглашения, переход на правильный сервер и сохранность входа,
транслирует движущийся canvas 1920×1080 по настоящему WebRTC, проверяет оба
направления ввода через тестовую подмену Windows IPC, отзыв и смену ролей.
Используйте `TANDEM_TEST_ICE` для ICE JSON. В управляемой облачной среде
политика Chrome запрещает прямой UDP: проверка выполнена через локальный
TURN/TCP на loopback. Политика браузера не изменялась.

`test/electron-smoke.cjs` отдельно запускает реальный Electron и проверяет
загрузку UI, preload/IPC, встроенный сервер и регистрацию через его WebSocket.

Реальная игра, Windows DLL, экран/звук Windows, аппаратный кодировщик,
интернет-маршрут и режимы 120–240 FPS **не проверены** этой Linux-средой.
Статистика RTT не заменяет измерение полной задержки нажатие → изображение.

## Профили и ограничения

По умолчанию 1080p/120, 35 Мбит/с, H.264. Видеотрек имеет `contentHint=motion`;
отправитель предпочитает сохранять разрешение при нехватке ресурсов.
Аппаратное кодирование выбирает Chromium; реализация кодировщика показывается
в статистике, когда браузер её предоставляет. Наличие мощной GPU само по себе
не доказывает, что используемый кодировщик аппаратный.

Режимы выше 120 FPS экспериментальны. Нет гарантии даже достижения выбранных
120 FPS на произвольной машине. Для паритета с Parsec на 4K/120+ дальнейшая
работа может потребовать нативного DXGI/WGC → NVENC/AMF/Quick Sync конвейера.
Здесь измеримый прототип для проверки вашего сценария, а не подтверждённый
профессиональный стриминговый движок.

Геймпады и драйвер виртуальной сети не включены. Из-за Windows UIPI игры
с правами администратора и некоторые античиты могут отклонять SendInput.
Защищённый рабочий стол и системные сочетания не передаются.
